# POS Supérette — تعليمات التشغيل

تطبيق PWA عربي RTL لنقاط البيع في محلات المواد الغذائية. HTML/CSS/JS خالص، بلا مكتبات خارجية ولا خادم خلفي.

## الملفات
`index.html` · `styles.css` · `manifest.webmanifest` · `sw.js` · `icon.svg` · `icon-192.png` · `icon-512.png`
`js/config.js` (إعدادات) · `js/logic.js` (حساب البيع والتقارير) · `js/db.js` (IndexedDB) · `js/license.js` (التجربة والترخيص) · `js/app.js` (الواجهة)
`tools/license-tool.mjs` (أداة البائع لتوليد أكواد الترخيص) · `tests/` (اختبارات)

## التجربة محليًا
```
cd pos-superette
python3 -m http.server 8080      # ثم افتح http://localhost:8080
```
## النشر على GitHub Pages
1. أنشئ مستودعًا وارفع محتوى المجلد (بدون `private.jwk.json`).
2. Settings ← Pages ← Deploy from branch ← `main` / root.
3. الرابط: `https://USERNAME.github.io/REPO/` (يجب HTTPS لعمل PWA).

## التثبيت على Android
افتح الرابط في Chrome (متصلًا بالإنترنت) ← قائمة ⋮ ← «تثبيت التطبيق» / «إضافة إلى الشاشة الرئيسية».

## التفعيل الأول
عند أول فتح تظهر شاشة «ابدأ التجربة المجانية». تحتاج اتصالًا بالإنترنت مرة واحدة: يقرأ التطبيق وقت الخادم (ترويسة `Date` من الاستضافة) ويسجّل بداية التجربة وبعدها 24 ساعة. بعد ذلك يعمل دون إنترنت.

## الترخيص بعد التجربة
1. مرة واحدة عندك: `node tools/license-tool.mjs keygen` ← الصق المفتاح العام في `js/config.js` (`publicKey`)، واحفظ `private.jwk.json` سرًّا.
2. الزبون يرسل «معرّف التثبيت» من الإعدادات.
3. أنت: `node tools/license-tool.mjs sign XXXX-XXXX-XXXX-XXXX` ← أرسل الكود للزبون ليلصقه في الإعدادات.
الكود مرتبط بمعرّف تثبيت واحد (هاتف واحد).

## النسخ الاحتياطي
الرئيسية ← النسخ الاحتياطي ← «تصدير» (ملف `POS-Superette-التاريخ.json`) — يعمل دون إنترنت وبعد انتهاء التجربة. «استرجاع» يتحقق من الملف ويعرض معاينة ويطلب تأكيدًا قبل الاستبدال.
**تنبيه:** البيانات داخل متصفح الهاتف؛ مسح بيانات المتصفح أو حذف التطبيق قد يمسحها. صدّر نسخة بانتظام.

## حدود الحماية
تمنع إعادة التجربة بإغلاق التطبيق/إعادة التشغيل، وتقفل التطبيق (قراءة فقط) عند إرجاع الساعة حتى مزامنتها بالإنترنت. لا تمنع مسح بيانات الموقع أو تعديل الكود من مستخدم متقدم.

## الاختبارات
`node tests/run.test.js` و `python3 tests/e2e.py` (يحتاج خادمًا على المنفذ 8765 وPlaywright).
